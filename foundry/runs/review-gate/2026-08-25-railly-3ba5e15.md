## Subsystem model

The Vercel edge routes public files first, then sends server documents through Astro middleware. Middleware classifies document requests, negotiates HTML or Markdown, and either returns agent content directly or preserves the page response. API, feed, sitemap, and asset routes bypass negotiation. Unknown document routes pass through the adapter's status-404 fallback, then gain HTML or Markdown recovery content.
