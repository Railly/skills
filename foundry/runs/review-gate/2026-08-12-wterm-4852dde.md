## Subsystem model

`WTerm.resize()` owns logical viewport position. `Renderer.setup()` owns DOM reconstruction and may synchronously destroy the geometry backing `element.scrollTop`. The scheduled render rebuilds scrollback spacers, after which the physical scroll offset can be restored.

The fix assumes the renderer recreates equivalent row geometry for the same history state. Its adjacent layer is resize coalescing: later resize events run after the browser has already clamped the DOM value, so they must retain the original pending offset instead of sampling zero. Bottom anchoring is the inverse direction and remains owned by `_shouldScrollToBottom`.
