## Findings

1. **High: MDX is served verbatim as Markdown.** `apps/web/lib/page-markdown.ts:127` appends `doc.content` directly. `/docs/commands.md` contains `<Properties>` and `<Property>` tags, while `/docs/index.md` contains `<Cards>`, `<Step>`, and `<Callout>`. Seven of eight docs pages use site-only MDX components, including component attributes that carry content. The core agent-readable output is therefore not ordinary Markdown.

2. **Medium: freshness metadata changes on every build or deployment.** `apps/web/lib/docs-pages.ts:17-25` uses `statSync(filePath).mtime`. In the production build every sitemap entry reports approximately `2026-08-14T21:12:20Z`, and every Markdown route reports `last_updated: 2026-08-14`. Git history for those files ranges from March 26 through August 8, 2026. The metadata describes checkout materialization, not content freshness.

3. **Medium: HTML 404 pages advertise the homepage canonical and Markdown alternate.** The global metadata in `apps/web/app/layout.tsx:13-18` is inherited by error pages. Both `/does-not-exist` and `/docs/does-not-exist` return HTTP 404 with `noindex`, but emit `canonical=https://ai-cli.dev` and `alternate type=text/markdown href=https://ai-cli.dev/index.md`.
