  warned at runtime.
- Named slot rendering is documented as a React capability, not renderer-wide
  parity.

## Findings fixed during the gate

1. The prompt initially advertised `default` as a named slot while also
   instructing models never to emit `slots.default`. The final prompt reports
   `"accepts children"` separately from named slot names.
2. `nestedToFlat` initially preserved nested slot node objects instead of
   flattening them to element keys. The final implementation recursively
   converts named slot children and covers the `data-spec` nested path.
