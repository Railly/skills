## Contract

Issue: `vercel-labs/agent-browser#1677`

Reviewed behavior:

- Emit URL messages for active main-frame full navigation.
- On Chrome, emit URL messages for History API and fragment navigation.
- Ignore child-frame and background-tab navigation.
- Keep the cached active-tab URL consistent with emitted messages.

Spec review: not provided.

## Findings fixed during the gate

1. Non-Chrome background full navigation could overwrite the active URL because `supports_screencast` bypassed session filtering. Fixed by applying active-session filtering to full navigation on every engine and keeping Chrome same-document support as a separate capability.
2. A late event from the previously active session could be attributed to the new active tab between `broadcast_tabs` and event-loop rebinding. Fixed by atomically binding the active CDP session with the tab cache and rechecking the live session immediately before publishing a URL.
3. Public prose initially implied same-document URL support on every engine. Fixed by scoping History API and fragment claims to Chrome.
