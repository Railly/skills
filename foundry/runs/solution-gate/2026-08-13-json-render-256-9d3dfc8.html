Failure-shape score

Proposal A

  • S1 designed out by preserving all strings.
  • S2 designed out through all renderers, validator, prompts, leading slash, and outside-scope cells.
  • S5 partial cost from public union and unregistered consumers.
  • S8 and S9 require domain-derived, force-red tests.

Proposal B

  • S1 fatal compatibility regression.
  • S4 leading slash is a proxy for intent that the existing contract does not promise.
  • S8 omits the historically valid slashless root cell.
  • S9 proposed validation test asserts the regression.

Accepted contract

  • string remains an existing root path.
  • { "$item": string } is relative only inside repeat scope.
  • Relative bodies "subitems" and "/subitems" resolve identically.
  • Outside scope returns no path, warns, validates as an error, and never reads root state.
  • The resolved path remains absolute for nested bindings, actions, filters, and indices.
  • Core validation, prompts, docs, Svelte, all framework renderers, and static render functions ship together.
