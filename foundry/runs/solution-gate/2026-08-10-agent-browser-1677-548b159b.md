## 0. Trigger

The gate fires because the fix changes the contract between CDP navigation events, the stream server's active-tab cache, and WebSocket consumers. More than one ownership shape was plausible before inspection.

## 1. Contract

**Property:** The streamed URL must stay synchronized with the active page's main-frame URL across every navigation category, without adopting background-tab or child-frame URLs.

**Observable:** A WebSocket stream client receives the new main-frame URL after full-document, History API, and anchor navigation. Background-tab navigation and child-frame same-document navigation emit no active URL change.

**Must not change:**

- Existing full-document navigation delivery for the active page.
- Active-tab cache updates.
- Screencast frame delivery and acknowledgement behavior.
- Non-Chrome behavior.
- Same-process and out-of-process child-frame isolation.
- Direct-page provider behavior, where the stored session is empty and CDP events omit `sessionId`.
- Stream wire format and dashboard consumption.

## 2. Confirmed defects and substrate facts

1. Current `cdp_loop.rs` handles `Page.frameNavigated` but not `Page.navigatedWithinDocument`.
2. A real stream received no `url` messages after main-frame `history.pushState` or fragment navigation, while `get url` reported the changed URL.
3. A real stream adopted a background tab's full-document URL and overwrote the cached active tab URL. The current full-navigation path does not filter by active session.
4. Main-frame and same-process child-frame `Page.navigatedWithinDocument` events carry the same active page session ID. Only `frameId` distinguishes them.
5. `Page.getFrameTree` returns the active session's top frame and is already used by `network.rs`, `a11y/mod.rs`, `state.rs`, and `actions.rs`.
6. Direct-page CDP connections use an empty stored session. Their CDP events omit `sessionId`, so session matching must normalize empty and absent as equivalent.

## 3. Forward chains

### Proposal A: local main-frame identity with conservative same-document emission

Main chain:

1. The stream loop calls `Page.getFrameTree` for the bound active page session. **Observed mechanism:** this command returned the top frame in live Chrome and is established in four repository call sites.
2. The loop stores the returned frame ID only for the current bind generation. **Inferred:** client or session changes recreate the inner loop, discarding stale identity.
3. `Page.navigatedWithinDocument` is accepted only when its `frameId` matches the stored main frame. **Observed basis:** live main and child events shared a session but carried distinct frame IDs.
4. The existing cache update and ordered `url` publisher run for History API and fragment navigation. **Inferred outcome:** the dashboard consumes the existing wire message without a client change.
5. Active stream URL follows all main-frame navigation categories. **Prediction for implementation.**

Helpful branch:

- Refreshing the stored frame ID on accepted main-frame `Page.frameNavigated` keeps identity current across cross-document navigation. **Inferred.**

Harmful branches:

- An awaited seed call before event processing can delay first-frame handling against a wedged renderer. **Inferred.** Design out by starting from `None`, keeping event processing live, and treating seed failure as conservative degradation rather than blocking stream startup.
- Frequent fragment changes add ordered-channel traffic and can increase lag for slow clients. **Inferred and accepted.** Every actual URL transition is part of the contract; no deduplication beyond identical consecutive URLs should be added without a separate measured need.
- Filtering only new same-document events leaves the observed background-tab full-navigation corruption intact. **Observed.** Designed out in synthesis.

### Proposal B: active-session plus main-frame routing with a shared publisher

Main chain:

1. `cdp_session_id` identifies the active page binding for the stream loop. **Observed, including updates on tab switch and browser connection changes.**
2. Event routing normalizes stored empty session and event absence, then rejects other page sessions. **Observed need:** background-tab navigation currently reaches the shared event receiver and corrupts the active URL.
3. Within the accepted active session, main-frame identity rejects same-process child navigation. **Observed need:** parent and child events shared one session ID.
4. A shared publisher performs the current active-tab cache mutation and ordered `url` send. **Inferred:** one sink prevents the navigation categories from drifting.
5. Full-document and same-document navigation obey one active-main-frame contract. **Prediction for implementation.**

Helpful branch:

- Direct-page providers remain covered when empty stored session equals absent event session. **Observed substrate, predicted preservation.**

Harmful branches:

- A stale active session suppresses correct events. **Inferred.** Existing `set_cdp_session_id` plus loop rebinding is the control; tests must cover tab switching.
- Applying a strict session predicate without direct-page normalization drops every provider URL update. **Observed substrate.** Designed out explicitly.
- Documentation churn across every user surface is unnecessary if the existing protocol already promises navigation URL events. **Inferred.** Limit docs to the canonical streaming protocol references that describe `url`, if clarification is needed.

## 6. Synthesis

**Kind: graft, with both proposals converging on the core mechanism.**

### Chosen shape

1. Keep navigation routing inside `cli/src/native/stream/cdp_loop.rs`.
2. For each bound Chrome page generation, derive a transient `main_frame_id` with `Page.getFrameTree`. Seed failure leaves it unknown and must not block stream startup indefinitely.
3. Normalize active-session matching:
   - A nonempty stored session matches the same event `sessionId`.
   - An empty stored session matches an absent or empty event `sessionId`, preserving direct-page providers.
   - Every other session is rejected.
4. Route both `Page.frameNavigated` and `Page.navigatedWithinDocument` through one shared active-main-frame publisher.
5. For `Page.frameNavigated`, require active-session match and the existing top-frame property, then refresh `main_frame_id` from `frame.id`.
6. For `Page.navigatedWithinDocument`, require active-session match and `params.frameId == main_frame_id`.
7. The shared publisher updates only the cached active tab and sends the existing ordered `{"type":"url"}` message.
8. Do not add a wire field, persistent state, polling, injected page script, dashboard change, or MCP change.

### What each proposal contributed

- Proposal A supplied the conservative per-bind frame identity, connect-after-load seed, and explicit cost of ordered-channel chattiness.
- Proposal B supplied the shared publisher and active-session ownership. The live background-tab probe upgraded its session filter from an assumption to a required part of the contract.

### Rejected material

- Handling only `Page.navigatedWithinDocument`: leaves the confirmed background-tab corruption in the same contract.
- Filtering only by session: same-process children share the active page session.
- Learning the main frame only from future navigation: misses clients attached after load.
- Periodic `Runtime.evaluate`: adds load and bounded staleness.
- Command-layer publication or injected page listeners: misses browser-initiated paths and alters page behavior.
- Broad documentation updates to unrelated CLI and MCP surfaces: no command or wire shape changes.

## 7. Carried assumptions and implementation verification targets

1. Seed `Page.getFrameTree` without creating an unbounded startup dependency. Verify against a mock CDP endpoint that never replies.
2. Exact force-red cells:
   - Active main-frame full-document navigation emits and updates cache.
   - Active main-frame History API navigation emits and updates cache.
   - Active main-frame fragment navigation emits and updates cache.
   - Same-process child History API and fragment navigation emit nothing.
   - Background-tab full-document and same-document navigation emit nothing.
   - A client attached after page load handles the first same-document navigation.
   - Tab switch rebinds session and frame identity.
   - Direct-page empty-session navigation still emits.
3. Remove session filtering and prove the background-tab test fails.
4. Remove frame filtering and prove the child-frame test fails.
5. Existing frame acknowledgement, latest-frame delivery, shutdown, and non-Chrome tests remain green.
6. Review Gate must drive every must-not-change item, not infer it from unit coverage.

## 8. Implementation handoff

The implementation should carry these predicates into `trail-decisions`:

- `event belongs to active page session, with empty/absent normalization`
- `event frame equals the seeded or refreshed top frame`
- `one publisher mutates active cache and emits existing wire message`
- `seed failure cannot indefinitely delay stream startup`

The must-not-change list in section 1 becomes the Review Gate checklist.
