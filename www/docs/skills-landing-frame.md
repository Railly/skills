## Problem

- The repository explains the methods, but does not provide a focused product surface for discovering and comparing them.
- Distribution channel and evidence maturity are independent concepts that are easy to conflate in a flat README.
- Copying install commands and understanding how methods connect requires scanning repository prose.
- A separate website must not widen or destabilize the installable skill surface.

## Outcome

- A polished, responsive Astro page at `skills.railly.dev` explains the evidence-driven approach.
- Visitors can browse all skills from repository-owned metadata, distinguish channel from maturity, filter the catalog, and copy exact install commands.
- A workflow view makes relationships among methods legible without claiming validation that does not exist.
- The app stays isolated under `www/`, builds statically, and deploys from the same repository through Crafter Station's Vercel team.
