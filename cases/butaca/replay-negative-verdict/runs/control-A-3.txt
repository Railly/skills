**Verdict: `legacyExport` is safe to remove.** The only reference anywhere in the monorepo is its definition in `packages/flags/src/index.ts`. I searched every package, app, script, CI config and infra file for `legacyExport`, `legacy_export`, `LEGACY_EXPORT`, and for "legacy" and "Export" being joined into one string, and found nothing else. Code can't reach the flag indirectly either: flags are only read through the typed `flags.get(name: FlagName)`, `FlagName` is a fixed list of names, `legacyExport` isn't on that list, and nothing looks flags up by computed name. Nothing outside the repo uses it: the flags package is private and has 0 dependents in the registry. The flag platform shows it archived since 2024-03 with 0 evaluations in the last 90 days in prod, staging and dev. Its purpose is also finished: it was added in 2022 for a migration that ended in 2023 (PR #812 merged, linked issue closed). What's left: this is a finding from the audit, not a completed change. The removal still needs its own small diff, with typecheck and the test suite run on it, as the evidence that it's safe. Deleting the archived record on the flag platform is a separate step from removing the code, and its owner should decide when to do it.
