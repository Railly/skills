## Contract and defect family

An append-paced patch to one element must not execute every unchanged element
renderer or catalog component. Stabilized bindings and resolved props must not
hide real key, state, repeat-scope, function, directive, loading, or structural
changes. The smallest wrong implementations are a disabled memo bailout, a
shallow comparison that ignores key ownership, or a comparator that omits one
reactive input.

## Falsification evidence

- Disabling the element-wrapper bailout changed the expected 226 directive
  executions to 5,226. Restoring it returned the test to 226.
- Removing the own-key check from `stabilizeRecord` retained `foo` when the
  next props contained only `bar`. Restoring the check produced `bar`.
- Removing binding stabilization restored the state-write update loop that
  reaches `Maximum update depth exceeded`. Restoring it completed with 26
  writes and no loop.
- Removing comparator inputs for repeat scope, computed functions, or
  directives made their focused assertions observe stale values. Restoring
  each input made the current-item and current-callback assertions pass.
- Replacing iterative signature traversal with recursive traversal caused the
  12,000-node graph to throw `RangeError`. The iterative implementation passes.
- Preventing error-boundary reset left the corrective-patch test blank.
  Restoring `resetKey` recovery renders the corrected value.

Every mutation failed at the intended behavioral assertion, not at compile or
test setup.
