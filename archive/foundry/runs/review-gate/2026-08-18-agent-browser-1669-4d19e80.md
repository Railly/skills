## Subsystem model

The CLI parses flags and commands, stamps a three-state CA transition, sends a launch envelope to the detached daemon, and the daemon resolves that transition against sticky session state before validating the launch family.

```text
Set | Omit | Clear
  -> CLI/config/MCP/Eve adapter
  -> parsed or explicit launch envelope
  -> daemon resolves effective CA
  -> launch-family validation
  -> browser/provider success
  -> commit effective session state
```

The dependency side is separate:

```text
run_certutil
  -> CLI install --with-deps
  -> Eve bootstrap + revision
  -> published sandbox helper
  -> environments helper
  -> benchmark copy
```
