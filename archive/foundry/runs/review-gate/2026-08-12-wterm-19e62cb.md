## Outcome

No open findings remain. The cross-family review found four concrete defects before commit, all fixed and covered at the shipped layer:

1. Built-in link indices were reused after RIS while scrollback and the JS cache retained old identities. Link-table lifetime now matches host `init()`, and a real-WASM regression proves destinations do not alias after RIS.
2. Truncated or malformed OSC 8 input left a previous link active. Every invalid OSC 8 path now clears active link state.
3. Plain clicks could both emit SGR mouse input and open a browser link. Mouse tracking now owns plain clicks; Shift-click remains browser activation.
4. Failed Ghostty hyperlink-buffer growth could decode from WASM address zero. The post-growth zero-pointer path now fails closed.

Earlier Review Gate findings were also fixed before this head: linked Ghostty spaces retain metadata, and built-in alternate-screen switches isolate active link state.
